Build a complete enterprise-grade Admin Control Center for ShoppieApp, a Zimbabwean marketplace platform built with Next.js, Supabase, Tailwind CSS, TypeScript, and Cloudinary.

The admin system must be modern, secure, mobile responsive, and accessible only to authorized administrators.

SECURITY REQUIREMENTS

Implement server-side and client-side protection.

Create role-based access control:

- admin
- moderator
- vendor
- user

Only users with role = admin can access the admin dashboard.

Protect all routes, API endpoints, and actions.

Unauthorized users must be redirected to the homepage with an "Access Denied" page.

Implement audit logging for all admin actions.

Store audit logs in Supabase.

Every admin action must record:

- admin user ID
- action type
- target user/product
- timestamp
- IP address if available
